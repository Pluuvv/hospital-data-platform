# Raw data

Download `healthcare_dataset.csv` from Kaggle and place it in this folder
(CSV files here are git-ignored):

https://www.kaggle.com/datasets/prasad22/healthcare-dataset  (CC0: Public Domain)

The dataset is synthetic (generated with Faker): 55,500 rows, 15 columns, admissions from 2019-05-08 to 2024-05-07.
